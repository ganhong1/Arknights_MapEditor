# 2.7.91 新增装置

2.7.81 的 847 个装置目录条目和既有图集保留为基线。工作台的装置、地形和美术资源库统一显示累计资源。装置用 ID 合并，翻板的三个 ID 各自保留。美术用 Unity 资源键合并，重复键使用新增包的条目，预览按该条目的原始 Bundle 依赖加载。

## 取证范围与配置入口

- Android 固定批次 `26-11-13-06-37-23-89286612` 的 `character_table.json` 与 2.7.81 对比新增 38 个 `profession=TRAP` 的 ID。38 个均在 Windows 固定批次 `26-11-13-06-34-18-84612175` 的 `pkgrps/btl_pfb_tokens_6.ab` 有独立预制体记录。
- 从 PC 的 3,084 个关卡 TextAsset 定位 29 份正文，经 TOR 同批次正文复核，5 个 ID 具有 LevelData 预设。共 308 条 `predefines.tokenInsts` 和 29 条 `predefines.tokenCards`。场上预设去掉坐标和朝向后有 93 份，卡牌完整去重后有 13 份，原始记录与出处保留。
- 32 件卫戍协议装备有 47 份玩法配置，来自 `activity_table.activity.AUTOCHESS.act3autochess.V3_1` 的商店棋子、效果与增益表。可露希尔的主题来自 `autoChessData.skinDataDict.ac_s_closur`。这 33 项的原版配置在各自装置详情的「卫戍协议原版玩法配置」展开。
- 自爆榴弹原版只有卡牌，数量出现过 3、4、5、6、8。三个翻板的角色表天赋黑板均记录 `stun=3`。自爆榴弹对应值是 `stun=5`。紧急部署信标的关卡样例均为场上。装置详情另有原版阶段、技能与天赋字段。
- 骨架图集使用 32 张原版商店图标、1 张主题图标、4 张装置头像和 1 张技能图标。紧急部署信标的原版模型和特效可在美术资源库预览。39 个逻辑入口（38 个装置 Prefab 和对应主题表入口）可从目录详情追溯。
- v3 总图从原装置区最后一格 `(11,46)` 接续。第一排为 `(11,47)–(11,67)`，第二排为 `(10,40)–(10,56)`。其中的装置实例用于骨架图标展示。原版调用从装置详情的关卡配置或玩法配置读取。
