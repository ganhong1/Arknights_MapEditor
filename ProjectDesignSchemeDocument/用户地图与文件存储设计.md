# 用户地图与文件存储

## 当前地图编辑器工作目录

开发分支、Unity 插件和设计文档在 ArkPathWeaver 的地图编辑器子仓库。下列路径均相对该仓库根目录。

| 用途 | 位置 |
| --- | --- |
| Unity 演示工程 | `.local/UnityProjects/WorkbenchDemoProject/` |
| 工作地图和 v3 总图 | `.local/Maps/Working/` |
| 冻结基准 v1、v2 | `.local/Maps/Baselines/prtsmap-v1/level.json`、`.local/Maps/Baselines/prtsmap-v2/level.json` |
| 5-10 路线、手牌示例 | `.local/Maps/Demos/Route-5-10/`、`.local/Maps/Demos/DeploymentCards/` |
| 未保存草稿与恢复副本 | `.local/UnityProjects/WorkbenchDemoProject/Library/ArknightsMapEditor/Recovery/` |
| 离线美术、音乐和音效 | `.local/Resources/Art/`、`.local/Resources/Audio/` |
| 历史验证与研究资料 | `.local/History/` |

Unity 演示工程通过相对路径引用 `unity/Packages/io.github.lingrs-llm-researchteam.mapeditor/`。旧资料路径通过目录联接继续可用，已保存地图和恢复文件仍可解析其中的原始路径。`.local/` 由 Git 忽略。工作台的「打开地图文件所在位置」按当前地图的保存路径定位文件，未保存地图会提示先保存。

## 面向用户的地图存储方案

首次使用选择“地图工作目录”，建议默认到用户选定数据盘；保存选择记在当前用户设置中。支持打开任意位置的既有 JSON，不强制迁移。新建只创建内存文档，第一次保存再创建地图文件夹。

```text
用户选择的工作目录/
├─ Maps/
│  └─ 地图名称/
│     ├─ level.json             # 游戏 LevelData 正文
│     ├─ project.arkmap         # 编辑器资源映射及项目元信息
│     └─ Assets/               # 此地图自有美术资源，可选
├─ Exports/                    # 用户明确导出的交付副本
└─ Backups/                    # 按地图稳定 ID 和时间保留快照
```

- 地图名称用于显示和文件夹命名，稳定文档 ID 用于恢复及版本关联；不把工作目录写入 LevelData。
- 保存使用临时文件写入后替换，成功后更新保存状态。对外部修改检查文件指纹，提供重读、另存和明确覆盖。
- 另存为生成独立地图副本，原文件保留；同名目标由用户确认。美术引用默认相对 project.arkmap，外部绝对引用在分享前列明。
- 分享提供“导出地图”和“导出工程包”：前者仅 LevelData，后者包含编辑工程与实际使用的可分发资源、清单及校验值。
- “最近地图”显示名称、绝对路径、修改时间和缺失状态；每项提供打开所在位置。改工作目录只改变今后新地图的默认位置；迁移须单独预览路径和冲突后执行。

## 其他文件存储方案

| 类别 | 保存位置 | 管理方式 |
|---|---|---|
| 内置地块、装置、敌人与关卡目录 | 插件只读包 | 随插件/资源版本发布，保留来源版本，不写用户修改 |
| 用户导入资源 | 用户资源目录 `Resources/` | 按来源与版本管理，可由多个地图引用 |
| 自动恢复草稿 | 用户数据目录 `Recovery/` | 独立于 Unity Library，保存文档、局部未应用编辑及关联地图；启动时按地图恢复 |
| 历史备份 | `Backups/` | 按数量和容量滚动保留，可手动固定关键版本；不得清理正在使用的恢复项 |
| 缩略图、索引、解包缓存 | 用户缓存目录 `Cache/` | 可重建；设置页显示容量并提供清理，不混入地图与原始资源 |
| 布局、搜索历史、最近地图 | 用户设置目录 `Settings/` | 与地图正文分离，跨地图复用 |
| 日志与核验报告 | `Logs/`、`Reports/` | 按日期和任务归档，可单独导出诊断包 |

设置页统一提供数据目录、缓存目录、占用空间、打开目录与备份保留策略。目录可选择 D 盘等数据盘，避免测试数据、资源副本和缓存持续占用系统盘。项目引用、缓存键均包含资源版本，2.7.81 与后续版本并存，不覆盖同名旧资源。

## 已实现的恢复与诊断

- 自动恢复保存完整快照，包括已应用正文、未应用草稿、保存基线、源文件路径及哈希、美术工程与局部草稿。仅在成功写入后更新已保存快照。临时 I/O 故障每 10 秒重新尝试，关闭或切换时再尝试写入。恢复文件损坏或哈希冲突时保留原文件，并为当前草稿启用新恢复文件。
- LevelData 正文的 16 MiB 上限沿用。恢复文件继续读写 v2 格式并读取 v1，使用独立的 256 MiB 外层上限。内部字段各自检查大小，覆盖多份正文和包含已保存版本的美术草稿。恢复文件通过原子替换更新。
- 「Tools → Arknights → Diagnostics」提供打开和导出日志。日志位于 Unity 工程的 `Library/ArknightsMapEditor/Logs/`，采用 UTF-8 JSONL，默认保留 10 个文件，每个 10 MiB，保留期为 14 天。通过事件 ID 可从界面提示定位操作、异常类型和堆栈。日志记录省略草稿正文、源文件路径及异常消息，导出按时间合并为单个 JSONL 文件。
