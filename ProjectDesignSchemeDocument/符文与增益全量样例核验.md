## 原版样例结构

```text
LevelData
├─ runes[]                         Legacy 关卡符文记录
│  ├─ difficultyMask               字符串枚举或整数位掩码
│  ├─ key                          原版符文 key
│  ├─ professionMask               字符串枚举或整数位掩码
│  ├─ buildableMask                字符串枚举或整数位掩码
│  └─ blackboard[]                 有序列表，可有重复 key
│     ├─ key                       string
│     ├─ value                     JSON number（整数或小数）
│     └─ valueStr                  string | null
├─ optionalRunes                   missing | null | {} | 分组对象
│  └─ <groupKey>[]                 与 runes 相同的五字段记录
└─ globalBuffs[]
   ├─ prefabKey                    string
   ├─ blackboard                   null | [] | 同上黑板列表
   ├─ overrideCameraEffect         本语料全部为 null
   ├─ passProfessionMaskFlag       缺失或 false
   ├─ professionMask               缺失或 NONE/0
   ├─ playerSideMask               缺失或 ALL/0
   ├─ useExtraData                 缺失或 false
   ├─ extraRuntimeData             缺失或 null
   └─ source                       缺失或 null
```

全部 runes/optionalRunes 实例只有上图五个字段，没有顶层 `id`、`type`、`selector`。不能把运行时 RuneData/Selector 对象字段直接加进这份 Legacy 原版样例结构。筛选相关数据还分布在 mask 和特定 blackboard 键中，实际解释由消费代码确定。

## 编辑器可直接使用的数据

1. 资源库按符文 key 或增益 prefabKey 建资源项，每项下面保留完整配置；不能将“一个 key”当成“唯一参数模板”。
2. 原版配置可展示/选用，推荐只是对既有样例的选择，不声称是运行默认值。optional 的组归属来自使用位置，应作为关卡编辑侧配置保留。
3. 黑板用有序条目编辑，允许重复、空列表；globalBuffs 同时保留 null。掩码用已核实源码枚举做控件，但导入的数字/字符串保持原表示。
4. 未观察到非空值的相机/运行数据/source 字段，仍应保留导入值；完整编辑结构需要源码继续补齐，不能据语料只有 null 删除字段能力。
