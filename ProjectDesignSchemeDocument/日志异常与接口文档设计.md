# 日志、异常与接口文档设计

确认日期：2026-11-14。适用于 Unity 2021.3 的 LevelData 编辑器。

## 实施范围

沿用 PluginLog 的 JSONL、异常类型记录和原子导出，补齐稳定错误码、操作关联、会话/文档/版本上下文、重复故障聚合、有界异步写入、保留策略及诊断窗口。输入错误显示在操作所在界面，内部异常附诊断编号，不自动重复弹窗。保留全部地图与局部草稿。

内部 C# 接口采用 XML 注释与 DocFX；文件契约采用 JSON Schema；HTTP 文档使用 OpenAPI 3.2.1 与固定版本 Swagger UI。当前无业务 HTTP 服务，文档明确实际可调用范围，不为生成文档额外创建服务。文档构建、契约校验与示例验证进入可重复执行的工具流程。

## 日志契约

- 事件：schemaVersion、utc、id、operation、level、category、code、operationId、session、documentId、revision、durationMs、outcome、exceptionTypes、stack。
- 默认本地目录位于项目 Library/ArknightsMapEditor/Logs；允许配置绝对路径。默认单文件 10 MiB、最多 10 个文件、14 天保留期。
- 有界队列：写入不调用 Unity API；失败状态及丢弃计数可查。退出/域重载有界等待，不无限阻塞编辑器。
- 默认不记录正文、草稿、用户路径及未经筛选的 Exception.Message。诊断包携带日志及环境摘要，地图正文不自动附带。
- 异常分类：validation、conflict、io、timeout、cancelled、internal。validation 与 cancelled 不弹故障窗口；内部异常为 error。稳定错误码与一次事件 id 分开。
- 重复错误在内存诊断列表聚合计数，记录首次/最近时间。日志自身故障不递归记录。

## 界面及边界

Tools/Arknights/Diagnostics 提供诊断窗口、打开目录和导出入口。窗口支持模块/级别/文本筛选、事件详情、文件写入健康、日志设置及短期详细日志。重载后读取最近日志，筛选不修改原始记录。

文档提交、撤销、保存及恢复入口带统一操作上下文。失败不清空草稿，清理错误保留为附属诊断而不替代原始异常。诊断是辅助能力，日志失败不使成功编辑回滚。

## 文件组织

- `Editor/Diagnostics/`：日志事件、错误分类、异步调度、文件存储、设置和 Unity 适配。移动现有 PluginLog 时保留 meta GUID。
- `Editor/UI/DiagnosticsWindow.cs`：诊断工具界面。
- `docs/`：用户/开发者文档入口、API 文档配置、文件契约、HTTP 文档说明。
- `tools/docs/`：文档构建和校验脚本，构建输出在忽略目录或 D 盘外部目录。
- `ProjectDesignSchemeDocument/`：保留既有设计、研究、计划，不批量移动已有资源和历史资料。

## 验收

新增定向测试覆盖分类、上下文、聚合、队列溢出、写入失败恢复、保留策略、导出、重载/关闭、配置和 UI。执行全量 EditMode 回归，检查日志新增模块覆盖率。文档工具验证 Schema/样例/链接并生成接口站点。记录实际输出和局限；刷新前后比较全部地图恢复快照。

## 实施与验证（2026-11-14）

日期：2026-11-14。Unity 2021.3.39f1，资源基线保持 2.7.81。

### 已实现

- `Editor/Diagnostics` 集中日志模型、分类、操作上下文、异步有界队列、文件轮转与生命周期管理。旧 `PluginLog` 调用保留，移动文件保留原 `.meta` GUID。
- 文档编辑、撤销/重做、保存和恢复操作记录文档身份、前后修订、耗时和结果。取消、校验拒绝、冲突、IO、超时与内部异常分别分类；清理异常保留在主错误上下文中。
- 诊断窗口支持搜索、模块/级别筛选、重复事件聚合、只读详情、写入健康状态、日志设置、限时详细记录和 JSONL/ZIP 导出。聚合后的每个事件编号与操作编号均可检索。
- 日志默认保存在项目 `Library/ArknightsMapEditor/Logs`，配置位于 `UserSettings/ArknightsMapEditor.Diagnostics.json`。默认每文件 10 MiB、最多 10 个、保留 14 天，可配置完整绝对目录。
- 日志不保存地图正文、用户路径和异常消息正文；记录异常类型及不含文件路径的调用栈。诊断包不包含地图文件。
- `docs/` 保存使用说明、运维说明、C# API、JSON Schema 和 HTTP 契约入口；`tools/docs/` 保存构建及校验工具。产物和缓存留在 D 盘外部存储。
- C# API 由 DocFX 从源码生成。Swagger UI 提供离线入口；当前没有业务 HTTP 服务，OpenAPI 的 `paths` 为空。
- 诊断回归集中在 `Tests/Editor/Diagnostics`，文件移动保留 `.meta`；更新文件结构说明与生成产物忽略规则。

### 复审修复

1. 期望的操作拒绝使用专用异常，避免标为内部程序错误。
2. 日志目录要求完整绝对路径，拒绝盘符相对路径等输入。
3. 导出遵守日志保留期限。
4. 设置变更先准备候选写入器和持久化配置，失败继续使用原写入器。
5. 重复错误聚合保存关联编号，诊断窗口同时索引关联事件与操作编号。
