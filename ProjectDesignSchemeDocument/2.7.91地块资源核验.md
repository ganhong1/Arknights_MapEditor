# 2.7.91 新增地块资源

关卡编辑器保留 2.7.81 取证与回归基线。右侧「地形」在同一资源列表中显示原地块和新增五种地块。地形详情沿用默认推荐、全部既有已知配置、关卡出处和骨架预览。已放置地块按原始 `tileKey` 显示和导出。

## 版本与复核

- Windows 客户端资源版本为 `26-11-13-06-34-18-84612175`。原版预制体入口为 `battle/prefabs/[uc]tiles.ab`。卫戍协议的可渲染子场景位于 `battle/prefabs/levelprefabs/activities/act3autochess/`，TL-1 主场景位于 `scenes/activities/act55side/level_act55side_01/`。
- 关卡配置、名称和 Buff 定义使用 TOR 的 2.7.91 同期数据 `26-11-13-06-37-23-89286612`。扫描原版 PC 关卡包确定出处范围，再以 TOR 同路径的 LevelData 复核字段与取值。[原版关卡表](https://torappu.prts.wiki/gamedata/26-11-13-06-37-23-89286612/excel/stage_table.json)
- 地块的目录、配置、关卡投影、黑板提示、检索元数据和头像图集从增量文件并入同一套资源库。骨架解析器直接识别新旧 `tileKey`。
- 「美术」合并基线包与增量包的资源目录，可按地块 ID 和中文名搜索部件、特效和场景。增量包在 `D:/Temporary_Embedded_Project/storage/map-editor-unity/terrain-2791/ArtPack2791`，同时收录[同批新增装置](2.7.91装置资源核验.md)。包内 `bundle-integrity.json` 记录来源校验值及压缩前后的序列化节点校验结果。

## 再生成

使用 `unity/verification/build-terrain-2791.py <证据目录> <Unity 包的 Editor/Catalog 目录>`。证据目录包含 Windows 预制体字段、TOR 原版关卡及各关卡的 SHA-256。美术包沿用 `unity/verification/art-resources/offline-pack/` 的构建和完整性校验流程。
