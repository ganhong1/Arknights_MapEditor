2026-11-14。原生基线 PC 2.7.81；本轮仅开发编辑器，不操作游戏实例。

## 数据边界

`mapData.blockEdges[]` 的记录为 `pos / direction / blockMask`；`tilesDisallowToLocate[]` 是 LevelData 顶层坐标集合，不移动到 mapData 内。UI 从地图数据模块提供入口，原 JSON 层级保持不变。已核实 PC 2.7.81 原生路径：该列表在地图初始化时将对应格子的运行时 buildableType 设为 NONE，不改 TileData，也不阻止敌人通行。界面使用“禁止部署格”；不将其描述成会覆盖所有脚本强制放置。固定来源、函数地址与字节摘要见 [原生消费核验](地图规则原生读取研究.md)。

方向为 UP=0、RIGHT=1、DOWN=2、LEFT=3，分别对应 row+1、col+1、row-1、col-1。blockMask 为 NONE=0、WALK_ONLY=1、FLY_ONLY=2、ALL=3。一条边双向阻挡；相邻格的反方向记录是同一几何边，重复记录对通行产生合并效果。历史记录保留原表示和未知字段。

地图规则使用独立的编辑模式和显示开关。点选边缘编辑阻挡边，点选或框选格子编辑定位集合；编辑锁阻止写入，相机锁只限制相机。导航与绘制互斥，双 SceneView 使用各自文档和规则上下文。

应用通过不可变文档事务，支持撤销/重做。拖拽作为一笔事务，Esc 取消；表单和地图操作发生冲突时先处理待应用草稿。未知枚举与非标准导入记录保留，不自动折算或删除。地图裁剪拒绝裁去已识别的规则坐标，并返回受影响的数据路径；完整冲突清单另行增强，不静默删改规则。

## 实现与验证（2026-11-14）

2026-11-14，Unity 2021.3.39f1，原生结构基线 PC 2.7.81。

### 已完成实现

- `mapData.blockEdges`：所属格坐标、方向与移动掩码表单，独立原始 JSON，格边点选/连续拖动。
- `tilesDisallowToLocate`：顶层坐标列表，点选/连续拖动/矩形框选。初始化时覆盖运行格部署类型为 NONE，保存时不改原 TileData。
- 显式场景操作更新同一几何边的已有记录并保留扩展字段；移除会删除该边的等价记录。导入时不自动合并或去重。
- 两类规则可独立显示；掩码 0 为灰色虚线，地面橙色、飞行蓝色、两者紫色、未知红色。
- 一次手势一次文档事务；Esc、切图、失焦取消未提交手势。表单有未应用草稿时拒绝场景写入。
- 原始 JSON 编辑后禁用旧索引卡片，刷新表单再编辑；严格解析保留未知成员、高精度数值与日期字符串。
- 裁剪拒绝裁去规则所属格并返回数据路径；不自动删除坐标或边。
