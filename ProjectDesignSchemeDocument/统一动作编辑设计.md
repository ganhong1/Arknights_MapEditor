# Waves / Branches 统一动作编辑

2026-11-14，基线 PC 2.7.81。用户认可后的实施设计。

Wave → Fragment 和 Branch → Phase 保留各自结构，Action 使用同一表单、目标选择器及校验。共用 19 个可序列化字段，不为动作新增游戏不存在的字段。

## 前端

- 动作卡片提供类型选择、适用字段／全部字段、字段树定位、复制重排删除和应用／还原。
- 适用视图按动作类型组织目标与路线、数量与时间、调度与阻塞、显示与计数、隐藏组与随机设置；全部视图遵循原字段顺序。
- 普通字重标题、完整边框和分层底色；切类型、切视图保留字段、草稿及展开状态。
- SPAWN 与 DISPLAY_ENEMY_INFO 选择本关敌人；SPAWN／PREVIEW_CURSOR 的路线库按主波次 routes、分支 extraRoutes 解析。PLAY_OPERA 复用已核实的命令路线解析规则。
- 激活／撤回选择预设别名；TRIGGER_PREDEFINED 用别名与能力名候选行编辑，序列化仍为原 key 语法。
- 剧情、对话、音乐、演出、玩法事件提供冻结来源的候选与自定义键；历史样例与已核实资源绑定分别标识，不等同运行可用性。
- 随机组、组包、整数权重和两个枚举可表单编辑；同组动作可查，不推算缺少运行上下文的最终概率。
- SHOW_ALL_HIDDEN_CARDS 不强制填写 key。E_NUM 不作为新增类型。EMPTY 保留随机候选语义，不当作普通分支执行器。

## 数据和校验

- 区分未提供、null、已赋值；导入未知字段、枚举表示和原值保留。
- 新增统一为新增动作，不要求所有类型都有敌人或路线。已存在动作按变更字段验证，类型切换重新检查新类型的必要目标。
- 同一操作保存整条动作并进入现有文档撤销事务。草稿继续分别由 WaveInspectorDrafts／BranchInspectorDrafts 绑定，不更改历史恢复身份。
- JSON 编辑与表单共享草稿，非法 JSON 保留输入；目标引用、数值类型与范围统一检查。运行态字段不主动生成。

## 联动背景音乐编辑

一个地图标签拥有一个 LevelData 文档会话。背景音乐、波次和分支共用动作草稿和文档历史。音乐页从 `waves[].fragments[].actions[]` 和 `branches[分支键].phases[].actions[]` 读取换曲动作，编辑实际的 `key` 和 `preDelay`。开局曲继续编辑根字段 `bgmEvent`。选曲和试听控件复用，完整动作表单保留全部字段。

- 新增时选片段或阶段，共用该节点的新增动作草稿，确认后由原调度编辑路径创建一条 `PLAY_BGM`。
- 定位用当前文档版本的动作地址。借助已有波次和分支历史重映射插入、重排、改名和撤销后的目标。草稿不再可定位时可从恢复入口处理。
- 草稿可跨入口继续，仅应用后修改正文。原始动作 JSON 待解析时留在共享草稿。操作沿用当前地图的撤销与重做。
- 以 2.7.81 音频事件索引查询开局和局中事件，历史音轨可供试听。海蒂的原键保留并提供显式替换，TN-3、TN-4 的四条引用可试听对应曲目并显示局中事件缺失。

实施时，音乐总览以本标签的当前文档为来源。编辑播放键和延时使用现有波次或分支草稿槽及提交路径；尚未读取的动作 JSON 标记随草稿保存和恢复。已知的结构更改重映射位置，直接替换调度 JSON 时清除无法确认的选中位置。开局沿用已有 `bgmEvent` 局部草稿槽，原始 JSON 和选曲表单共享应用与撤销。

## LevelData 同一性复审修订

一个地图标签通过一个 DocumentSession 编辑 LevelData。同一文档的双场景视图共用会话。分支动作和已识别的关联引用都以同一份保留原数字和扩展字段的结构为底稿。仅应用显式编辑，不借撤销、重做或视图切换提交完整 JSON。

局部草稿使用原目标和其依赖的基线。正文的无关字段变更时继续使用同一草稿，目标或依赖变化时保留冲突草稿供处理。恢复或替换正文时重置旧调度选中地址、视图和结构操作历史。音乐总览与动作表单使用同一份草稿，刷新列表内容时保留编辑控件焦点。LevelData 中心字段树仍显示已应用正文。

已落地的重基准覆核用于环境音等稳定的根字段。波次和分支的动作位置仍由各自的引用与结构历史维护。数值保真的分支读取同时兼容原版黑板上的整值小数，如 0.0。恢复快照里的开局曲草稿会先核对目标字段，再核对版本和原值。

## 工作台字段绑定与音乐资源库

每个地图标签的编辑命令、恢复副本和撤销记录属于本标签的 DocumentSession。恢复时按快照中的目标重新初始化草稿面板。索引受编辑、撤销或重做影响时，仅在能确认同一记录时沿用选择。目标变动的草稿保留原文并提示冲突。

mapData、路线和关卡预设按各自的字段或集合比较基线。只有无关字段变动时才续用已有草稿。高级编辑的字段选择、正文和草稿目标同步变更。预览读取已应用正文，文件保存要求先明确处理完整 JSON 草稿。

右侧「音乐与音效」收纳曲目搜索、卡片、详情和试听。左侧开局、波次与分支编辑器保留播放事件键、调度参数和应用。资源库选用写入发起入口的同一份草稿，并检查当前标签和选曲目标。原版音频索引和历史音轨来源随曲目展示。


## 音乐与音效的两种浏览方式

「音乐」和「音效」是右侧资源库的一级分类，与「地形」「装置」同级。同一分类框内的「试听包」按钮可选择音乐包或音效包。进入音乐或音效后可切换「按用途／按原版事件」。音乐沿用「开局曲／局中换曲」，音效按环境底声、天气与全图机制、地块音效、装置音效、关卡演出、玩法与操作反馈及各自细类浏览。原版视图按 2.7.81 的事件模块和信号分组。完整事件名保留原文，子信号可为空或内含句点。别名按调用键归组，详情显示目标事件。

两种视图共用搜索、虚拟列表、选中高亮、详情及试听。用途视图在同一分类内合并复用的音效片段，原版视图按事件展示其候选音轨。播放文件以资源包索引为准，原版登记和试听状态分别显示。原版音乐目录覆盖 577 个播放记录和 230 个别名，音效接入已核验的 227 个事件和 144 段音频。

从 bgmEvent、PLAY_BGM 或 environmentSe 打开时按发起字段限定可选事件。切换视图保留搜索词、选中记录、试听和字段目标。只有「选用」会写入发起字段的现有草稿。恢复、应用、撤销沿用地图标签的文档会话。

资源详情顶部内置试听播放器。进度条显示当前时间和本次试听的总时长，拖动后定位。播放、暂停、停止和试听音量只影响编辑器内当前试听。音乐可以试听前奏加一遍循环段、单独听循环段，或从换曲动作试听过渡。音效事件可选择已取得的候选音轨。关掉详情会停止详情内的试听。

音乐和音效共用 CatalogSearchInput 与 CatalogSearchRuntime。资源目录通过 AudioLibraryCatalog 提供搜索文档，名称、事件键、别名、音轨路径和分类分别进入 Fuse.js 对应的字段。成品关卡、装置、敌人等模块也使用同一检索运行时。地形和关卡出处的拼音与预建索引仍由各自目录适配。分类切换保留关键词，清空搜索恢复当前分类列表。

音频详情依次显示试听、用途与调用、音轨和折叠的技术详情。原版事件与资源键支持复制。技术详情展开时，从当前试听包清单定位音乐或音效的本地 Ogg，使用与播放器相同的文件校验。点击普通文字样式的本地路径，在文件管理器中定位该文件。资源版本由目录和试听包索引维护。
