# LevelData 编辑器使用说明

## 版本与当前状态

首个支持基线为 Unity **2021.3.39f1**、Windows 编辑器。其他版本、平台与渲染管线尚未建立完整兼容矩阵。包最低版本声明不是所有后续版本均已测试的证明。

当前为开发预览。源代码已接入文档、SceneView 示意、地图编辑、目录、恢复及独立工程配置；完整验收以仓库 `unity/evidence/P0_P6_CHECKPOINT_20261103.md` 和之后的测试记录为准。本说明不宣称 P5 完成，不宣称任意地块、装置或游戏内效果已验证。

## 安装

1. 使用独立 Unity 2021.3.39f1 工程，建议工程与 Library 放在 D 盘。
2. Package Manager → Add package from disk，选择本包 `package.json`。安装的是包目录，不是仓库顶层。
3. 等待声明的 Newtonsoft 依赖解析与编辑器编译。
4. 打开 **Tools → Arknights → Map Editor**。

不需要安装 MCP、Python、Rust、游戏客户端或 Torappu 程序集。Git 安装渠道需可访问的已提交版本，当前本地未提交工作区不能当成已发布 Git 包。不要手工向工程复制另一份 Newtonsoft DLL。

## 文档和地图

- 打开已有 LevelData JSON，或新建文档。JSON 顶层以原生数据为准，未知字段保留。
- 完整 JSON 草稿须先应用或撤销，再使用结构化编辑工具；错误草稿可保存到恢复副本。
- 地块库只允许从完整冻结模板创建。目录示意定义或名称存在，不代表已经取得原生配置模板。
- 当前冻结目录64个去重ID、23个完整模板和23条中文资料。不是116或119个地块的全覆盖声明。
- 地图示意使用 Unity SceneView；视角控制沿用 Unity。绘制、尺寸调整及拾取的具体快捷键以窗口提示为准。
- `predefines`、隐藏输入、卡牌与原生机制动作分别处理，不能把所有ID都当成普通可放置装置。
- 路线、敌人、波次、Branch 与其余原生配置可通过相关字段或完整JSON编辑。校验覆盖实现的结构与引用规则，不模拟游戏机制。

## 保存与冲突

保存前对比原文件SHA-256；外部改变或删除会拒绝覆盖。另存采用新文件创建语义，目标已存在时请选择新文件名或先明确打开它。写入使用同目录临时文件和替换，不删除旧文件后再尝试写入。

这是乐观冲突检测，不是跨进程原子比较交换；外部程序恰好在最终校验与替换之间修改文件仍可能存在竞争。尽量保持同一文档单写入者。

## 恢复

恢复文件位于宿主工程 `Library/ArknightsMapEditor/Recovery`。自动恢复缓存按会话UUID隔离，保存时仍需要持有该缓存的摘要。手动“保存恢复副本”和“恢复草稿”提供显式入口；恢复不会直接写源文件。

自动缓存不是永久备份，也不能保证崩溃前最后一次输入已写入。删除Library会丢失缓存；重要成果仍应保存到正式文档并使用版本管理。恢复未应用草稿后，需修正并应用再保存。

恢复v2将文档、未应用全文、局部表单草稿及独立美术配置写入一个原子快照；兼容v1的文档恢复。局部草稿绑定原文档摘要和目标，切换文档或目标后拒绝应用旧草稿，须明确重新读取。非法JSON草稿可保留；保存正式关卡前需应用或明确丢弃局部修改。

## 独立编辑工程与美术配置

`.arkmap` version1 保存相对 LevelData 路径和独立 artMappings。资源路径使用正斜杠，禁止绝对路径、`..`、链接穿越和设备名。移动工程时保持相对目录结构。

Unity GUID 仅为编辑器资源定位信息，不等于游戏路径。该配置目前不构建AssetBundle、不注入资源、不保证HG Shader或游戏美术生效。没有对应资源时保留配置并诊断，不能静默替换为默认资源。

## 示例

`Samples~/BasicMap` 为自制2×2文档，包括普通地形和未来字段保留示例。不携带游戏美术或运行配置，不承诺直接进入游戏。可使用复制后的样例编辑；不要往安装包目录写入用户成果。

## 卸载与问题报告

先保存正式文档、导出需要保留的恢复副本并关闭编辑窗口，然后在Package Manager移除包。卸载不应清除用户关卡或修改用户场景。候选02已在独立工程完成安装、卸载、再安装及三轮Win64 Player构建，用户自制场景摘要保持一致，MapEditor程序集未进入Player。此结论不自动覆盖候选之后的新源码。

报告问题时提供Unity版本、包版本、操作步骤、最小自制JSON、预期/实际结果和相关错误日志。请勿上传账号信息、游戏私有资产或整份Library。注明问题发生在数据编辑、示意视图、文件保存或游戏运行，避免混淆验收范围。
