# LevelData 装置既有配置与出处核验

日期为 2026-11-06。本轮只整理原版数据、离线研究工具与测试，没有修改 Unity 插件代码，没有操作游戏、实验服或 Unity 草稿。装置资源库的接入方案仍处于讨论阶段。

## 数据与范围

原始输入沿用地块样例的同一固定数据源，即 APW 资源根下 `source/ArknightsGameData/zh_CN/gamedata`。Git 提交为 `bb8f9ac8db143a661577ed6ef5184d3c6e93d1d0`，扫描前后身份一致且工作数据干净。

全量枚举 `levels` 下 3,901 个 JSON，其中 3,899 个为可识别 LevelData，另两个为敌人数据库与 levels_meta。遍历全部正文的 `predefines` 和 `hardPredefines`，分别提取 `tokenInsts` 与 `tokenCards`。包括无地图布局的正文，不按地块引用、主线类型或装置 ID 前缀筛选。

每份配置保留原始字段、完整 JSON 指针和正文相对路径。正文归属通过 `stage_table` 及 `battle_misc_table.levelScenePairs` 的单次精确键映射补充，多个 stage 条目引用同一正文时，出处仍只计一份正文。正文路径作为本快照的出处标识，内部 levelId 不作为唯一键。

## 去重的两个层次

**完整记录去重**忽略对象键顺序，其余字段全部保留。数组顺序、重复黑板键、字段缺失、null、空数组、整数／浮点以及枚举字符串／数字表示均保留差异。原文件的字节差异另由源文件 SHA-256 追溯。

**配置比较投影**用于判断记录差异是否主要来自摆放或关联信息。

| 类别 | 仅从比较投影中移除 | 继续保留 |
| --- | --- | --- |
| tokenInsts | position、direction、hidden、alias | inst、技能选择与等级、外观、技能／天赋覆盖、未知附加字段等 |
| tokenCards | hidden、alias | initialCnt 以及其余全部字段 |

投影不表示完整使用条件等价，也不是可直接采用的默认模板。被移除字段仍在原始样例中完整保存。每份投影保留对应完整样例集合，每份完整样例再列出所有正文、预设容器和数组索引。

历史导出中存在数字与字符串枚举混用、缺失字段与显式 null 并存，以及 skinId 的 null／空字符串差异。本轮未根据猜测补默认值或归并这些形态，所以配置数量包含真实参数差异和序列化形态差异。

## 843、846 与 403 的关系

当前 character_table 以 `trap_` 前缀或 TRAP 职业取并集，共 843 个静态 ID，其中 402 个在本轮两类预设中出现，441 个未出现。

历史 BattleLab 总表的 846 个 ID 比当前静态表多三个条目，本轮保留差异记录。

| ID | 历史总表名称 | 当前静态表 | 当前 LevelData 两类样本 |
| --- | --- | --- | --- |
| trap_004_iceblock | 封印的地面 | 未收录 | 未观察到 |
| trap_017_wooden_broke | 破损的木桩 | 未收录 | 未观察到 |
| trap_047_mandrablock | 封印的地面 | 未收录 | 未观察到 |

按历史 846 项目录计算，402 项有原版预设样例，444 项未观察到。未观察到不表示装置不存在或不能运行，其输入也可能来自模式、技能或其他机制。

此外，场上记录实际包含 `token_10053_radian_tower3`，静态名称为“桑特拉”，职业为 TOKEN。它有静态定义，也有原版关卡出处，应独立保留，不能被 trap_ 前缀过滤。因此本轮预设记录涉及的不同 ID 为 402＋1＝403。

## 出处完整性

每个装置在 `CONFIGURATION_INDEX.md` 中先列总出处，然后分别列场上／卡牌的每份配置及当前配置出处。场上／卡牌不互相转换，常规／困难预设指针不合并。

stage_table 中 3,359 个条目能映射到本地正文，涉及 2,359 份正文。201 个条目没有正文 ID，另 10 个正文引用未在本快照解析。这些状态分别计数。带装置记录的 2,763 份正文中，1,688 份有 stage_table 关联资料，其余 1,075 份仍提供完整资源路径，不能据文件名猜测关卡名或模式。

## 资源库接入的待讨论建议

1. 目录仍按装置 ID 展示，每项分别提供“场上预设”和“卡牌记录”两类既有配置，不把卡牌强制转换为场上实例。
2. 继续支持“全部既有配置”“当前配置出处”“总出处”。样例规模足以支持完整浏览，默认推荐的规则需另行讨论。
3. 比较投影可帮助归组。实际选用时仍须明确处理位置、朝向、hidden、alias 和黑板中的关卡关联，保留完整原样例供核对。
4. 以 branch、alias、区域和坐标相关参数提示需要复核的上下文。波次和分支编辑继续由对应独立模块承担，资源库不静默复制整份调度结构。
5. 未见样例的目录项仍可展示，但不能生成一份声称来自原版的默认配置。编辑器应区分“有原版样例”和“仅有静态定义”。

以上为本轮研究建议，尚未修改插件行为。
